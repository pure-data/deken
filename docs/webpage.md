Deken Webinterface
==================

To interactively explore the deken package index, you can use
[https://deken.puredata.info/](https://deken.puredata.info).

There you can search for libraries, object and object descriptions,
and limit the results to specific architectures.

The webpage allows you to explore the various uploads
(including a listing of the library's objects - at least if the uploader provided this information)

On the page for a given package, you will also find a link to the package download itself.
Using this link you can download the deken package and install it manually via deken
(e.g. if the Pd computer is not connected to the internet).
